# Database Guide

Appunti di studio sui **database relazionali**, scritti durante il modulo Database del percorso Web Developer AI presso la Steve Jobs Academy (Catania).

La guida parte dalle basi (cos'è un dato, perché esistono i database) e arriva al modello relazionale, ai vincoli di integrità, all'algebra relazionale e alle viste. È teoria pura: la sintassi SQL non è trattata qui.

---

## Un'idea per orientarsi

I capitoli 03 e 04 sono il ponte tra matematica e database: una tabella non è altro che un **insieme di tuple**, cioè un sottoinsieme di un prodotto cartesiano. Tutto il resto (chiavi, vincoli, algebra) si regge su questa idea.
